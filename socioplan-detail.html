研究概览

SocioPlan 研究真实微博热点事件评论区的讨论轨迹如何随时间演化。给定事件、已观测评论前缀和后续用户状态，模型需要自回归生成后续讨论轨迹，并在群体层面复现真实讨论动态。

项目的核心主张是：相比直接自由文本生成，结构化社会决策层能够提供更可解释、可控、可干预、可优化的中间接口。

核心方法

state → Full-8 structured decision → comment

本项目把长期群体动态优化从自由文本空间转移到结构化社会决策空间。Planner 首先预测八维社会决策，再由条件生成器将决策实现为自然语言评论。

系统架构

SocioPlan 的实现被拆成数据层、特征层、模型层、训练层、实验层、评测层和强化学习层，核心思想是把“社会讨论生成”拆成结构化决策预测和条件文本生成两个子问题。

模块职责
标签与动作空间模块定义 Full-8 维度、标签顺序、默认 action，以及 annotation 到 Full-8 action 的映射。
状态构造模块构造 planner 输入，包含 Topic、Step、UserProfile、RecentContext、PopularContext 和 PrefixStats。
Planner 模块实现 Full8Planner：hash token + EmbeddingBag mean pooling + 八个分类 head + value head。
文本生成模块封装 lightweight smoke generator 和 HF/Qwen 生成器，并清洗生成评论。
标签投影模块将生成评论投影回 Full-8 action，保证生成文本可以进入轨迹级评测和 RL reward。

为什么这样设计：直接生成评论很难做长期优化；Full-8 action 层把不可控文本空间转成可监督、可采样、可计算 reward 的离散决策空间，后续再由条件生成器把 action 实现为自然语言。

实验协议

  • 采用 event-level 7:3 划分，避免同一事件评论同时出现在训练和测试中。
  • rollout start 设置为 K=50，模型观察前 50 条真实评论后自回归生成后续轨迹。
  • 所有方法共享相同事件集合、相同 Full-8 标签空间、相同投影器和相同评测指标。
  • 对比 Direct Generation、State、Recent、Popular、MF-LLM、Ours-BC、Ours-PPO / GRPO。

训练方法

Behavior Cloning

使用专家行为轨迹训练 Full-8 planner，提供稳定 warm start。简历中的 71.33% mean action accuracy、rumor / belief 维度 92.60% / 88.81% 来自该阶段的多任务 planner 验证结果。

BC 训练流程读取 Full-8 行为克隆样本，把每条样本的状态文本输入 Full8Planner，对八个维度分别计算 cross entropy 并求和训练。验证阶段逐维统计 accuracy，并汇总 mean accuracy，训练产物会保留模型权重和评测摘要。

PPO / GRPO

在 rollout-level 优化长期群体轨迹。GRPO 实现中，同一 state 采样 group_size 个候选 Full-8 action，对每个 action 调用 conditional generator 生成评论，再用 projector 恢复标签并计算 decision / consistency / population / terminal reward，最后做组内相对标准化更新 planner。

候选采样 对八个维度分别从 categorical distribution 采样，累计 action logprob 和 entropy，形成同一 state 下的一组候选 Full-8 action。
奖励分解 decision reward 衡量预测 action 与 gold action 的逐维一致性；consistency reward 衡量预测 action 与生成文本投影回来的 recovered action 是否一致；population / terminal reward 衡量生成前缀分布与真实前缀分布的相似性。
GRPO 更新 对同一 group 内 reward 做均值方差标准化，使用 clipped ratio policy objective，同时保留 BC auxiliary loss、entropy bonus，并可选 OPD teacher KL distillation。

Rollout 实现

自回归 rollout 流程中，每个事件先读取前 K=50 条真实评论作为 prefix，再从第 51 条开始逐步生成。

读取事件 split 构造 prefix counters build_state_text Planner 预测 Full-8 Qwen 条件生成 更新前缀状态

state 构造中包含最近评论、热门评论和八维前缀统计：热门评论按 followers_count、comments_count、reposts_count 组合排序；PrefixStats 记录每个维度当前累计分布。这样 planner 不只看单条评论，而是看到事件主题、目标用户画像、局部上下文和群体分布状态。

分布式生成时支持按负载均衡切分：系统会按每个事件待生成步数分配任务，避免长事件集中到同一 shard。生成流程还支持断点续跑，会读取已有生成结果中的 completed rows，恢复生成评论和 action 后继续更新 prefix counters。

评测指标

指标含义
Accuracy / Macro-F1 / Micro-F1个体行为决策预测质量。
KL Divergence群体分布拟合程度。
Wasserstein Distance生成轨迹与真实轨迹的分布距离。
DTW Distance时间序列相似性。
NLL Losslikelihood diagnostic，用于辅助解释 one-step likelihood 与 rollout fidelity 的差异。

指标计算流程先按事件分组并按时间步排序，然后对每个维度计算 accuracy、macro-F1、micro-F1、KL、Wasserstein 和 DTW；最后再聚合到 dimension-level 和 overall-level。DTW 会对长序列做下采样，避免超长评论轨迹造成评测开销爆炸。

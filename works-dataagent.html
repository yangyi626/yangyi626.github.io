真实案例回放 · 非在线运行PHASE 1 DEMO / task_89 / easy

真实问题 · 中文释义

2008 年中国大奖赛中，第二名车手的完赛时间是多少？

What's the finish time for the driver who ranked second in 2008's Chinese Grand Prix?

以下五阶段是对 19 步历史工具轨迹的编辑分组，并非原系统的五个界面。代码与反馈按原文节录；不展示模型内部思考，不在网页执行 Python 或调用模型。

TASK INPUT / 工具步骤 3

把问题，落到两个数据源。

任务限定年份、赛事和最终名次，目标只是一列 time。历史 listdir 返回成绩 CSV、赛事 JSON 与知识说明。

  • csv/results.csv — 成绩记录
  • json/races.json — 赛事记录
  • knowledge.md — 随题知识
需要区分的字段

随题知识将 raceId 定义为跨表关联键，并区分最终完赛顺序 positionOrder 与最快圈速排名 rank。

知识说明摘意，作为读者补充；该轨迹未记录读取 knowledge.md 的动作，不声称 Agent 已使用它。

OBSERVE & REPAIR / 工具步骤 4–10 · 节录

数据长得像列表，不代表它就是列表。

inspectfile 超时后改读文件。第一次 Python 直接遍历 JSON 顶层，返回类型错误；随后检查实际结构，发现记录包在 records 中。

year / name

time

PYTHON / 工具步骤 17 · 原代码节录

按赛事定位，再取第二名的时间。

此案例真实使用 Python，不补写一段未运行过的 SQL。下方节录保留读取、筛选和结构化输出；省略原代码的注释与空行。

import json
import csv
with open('json/races.json', 'r') as f:
    races_data = json.load(f)
races_records = races_data.get('records', [])
race_id = None
for race in races_records:
    if race['year'] == 2008 and race['name'] == 'Chinese Grand Prix':
        race_id = race['raceId']
        break
if race_id:
    result_time = None
    with open('csv/results.csv', 'r') as f:
        reader = csv.DictReader(f)
        for row in reader:
            if int(row['raceId']) == race_id and int(row['positionOrder']) == 2:
                result_time = row['time']
                break
    result = {"columns": ["time"], "rows": [[result_time]]}
    print(json.dumps(result))

02 EVOLUTION, NOT A SINGLE LEAP

从补充字段含义，
到按风险组织求解。

这不是把一次失败包装为已修复的故事，而是把不同阶段的工作分开说明。上面的回放来自个人参赛代码的本地运行；下面的赛后模块属于另一条复现与优化路径。

  1. 01 / 官方基线 · 上游

    工具反馈驱动 ReAct

  2. 02 / 参赛阶段 · 个人增量

    让字段带着语义返回

    把含义、格式与枚举说明附到工具 Observation；按实际输出列筛选，管理长程历史。推断补全不等于数据事实。

  3. 03 / 赛后 · 复现上游冠军方案

    统一数据，保存求解程序

    复现 DuckDB 多源加载与持久化 solver，通过探索、读取、编辑、执行继续修正。冠军成绩与底座归上游团队，不是本人获冠军。

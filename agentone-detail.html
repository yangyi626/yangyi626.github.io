经历概览

项目启动初期加入，主导 Agent-One 核心模块从 0 到 1 搭建，围绕云端 Agent 运行框架、Skill / Memory 系统、Harness 评测进化与端侧 Agent 模型训练，构建“任务执行—轨迹采集—失败归因—版本评估—策略优化”的 Agent 工程闭环。

阶段一：Agent-One Framework

云端 Agent 运行框架与 Skill / Memory 系统

  • 负责 Agent-One 云端 Agent 运行框架设计与核心链路实现，围绕任务输入、意图解析、步骤规划、工具调用、结果校验与执行日志，构建可扩展的 Agent Runtime，为后续 Harness 评测与端侧模型训练提供统一执行入口。
  • 设计并实现 Skill 管理机制，将文档处理、文件操作、终端执行、数据归档等高频任务流程抽象为可复用 Skill，统一维护 Skill 的参数配置、触发条件、工具依赖与权限边界。
  • 构建 Agent Memory 与上下文管理模块，对用户偏好、历史任务、工具反馈、执行状态与中间结果进行结构化组织，支持多轮任务中的上下文注入、历史压缩与状态恢复。
  • 封装文件、终端、浏览器、NAS 等基础工具调用接口，统一工具输入输出协议、异常处理、超时控制与执行日志，为 Trace 采集、失败归因和版本回归评测提供可观测的工具执行层。

阶段二：Agent-One Harness

Agent 评测进化、Trace 采集与失败归因

  • 面向 Agent 在复杂终端与跨工具任务中执行不稳定、失败原因难定位、Prompt / Tool 改动难评估等问题，构建 Agent-One Harness 评测进化框架。
  • 将 Prompt、Tool、Runtime、Sandbox、Validator、Trace、Evaluator 等能力抽象为可版本化组件，支持 Harness 版本的候选评估、回归对比与晋升发布。
  • 接入 Terminal-Bench 2.0 真实终端任务集，开发任务适配、环境初始化、批量运行、断点续跑、Trace 保存与 pass@1 统计流程，支持 Easy / Medium / Hard 共 89 道任务的自动化评测。
  • 基于真实失败样本迭代 Harness 版本，系统优化 Runtime 超时控制、LLM retry 策略、Sandbox 隔离逻辑、工具调用约束、任务 contract 解析与 verifier 适配流程；优化后 Easy 子集达到 pass@1 = 100%。
  • 构建 Trace 采集与失败归因流程，对 Agent 运行轨迹、工具调用结果、环境反馈、失败证据、错误类型与任务得分进行结构化建模，将失败原因归因到 Prompt、工具协议、运行时、沙箱环境、任务 contract 或 verifier 层面。

阶段三：Agent-One Learning

基于稳定轨迹的端侧 Agent 模型训练

  • 基于阶段二稳定 Harness 产出的高质量执行轨迹，搭建端侧 Agent 模型训练流程，打通任务 rollout、轨迹清洗、reward 构造、在线训练、policy 回灌与 holdout 评估链路。
  • 使用 Qwen3.5-4B 作为端侧候选模型，设计多步轨迹数据结构，记录 messages、tool traces、tokens、masks、logprobs、reasoning、环境反馈与任务结果，将 Agent 执行过程转化为可训练、可评估、可复盘的结构化样本。
  • 构建 Trace Feedback 与 Reward Modeling 机制，结合任务通过率、动作合法性、工具调用有效性、步骤冗余度、答案一致性、失败类型与轨迹质量等信号，对轨迹进行自动化打分、样本筛选与训练数据构造，为 GRPO 策略优化提供奖励信号。
  • 接入 Atropos online trainer 开展 rollout 在线强化学习，在 holdout 任务集上对比 base / trained policy，验证轨迹反馈到策略优化的闭环效果。

能力沉淀

  • Agent 工程能力：从 Runtime、Skill、Memory 到 Tool Calling 协议，完成可扩展、可观测、可复用的 Agent 执行底座设计。
  • 评测与稳定性能力：将真实终端任务、Trace 证据、失败归因与版本晋升连接成持续进化闭环，支持 Prompt / Tool / Runtime 改动的可量化评估。
  • 训练数据与反馈建模：将 Agent 执行轨迹转化为结构化训练样本，并通过 reward 信号把任务结果、动作质量和轨迹质量反馈到策略优化过程。
  • AIPC 场景理解：围绕 PC、手机、NAS 多端协作链路处理权限、审批、归档、上下文恢复与任务状态管理等实际工程约束。

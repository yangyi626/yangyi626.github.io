Skill 进化

构建执行反馈驱动的 Skill 自进化闭环，使 Agent 能够从真实任务轨迹中识别能力缺口，并把重复出现的失败模式沉淀为可复用能力。

使用归因基于任务轨迹分析 Skill 是否被正确触发、调用和完成，区分能力缺失与使用不当。
缺口诊断聚类重复失败，定位缺少的步骤、工具依赖、验证条件与异常处理策略。
自动迭代根据诊断结果生成或更新 Skill，明确触发条件、执行流程、工具约束与产物要求。

可信发布：候选 Skill 必须经过安全校验、隔离评测与版本管理后才能发布，并支持跨任务复用与失败回滚。

Harness 进化

设计面向任意 Agent 的非侵入式 Debug 插件，在不改动 Agent 主体实现的前提下，读取真实运行轨迹并自动完成失败归因、受控修改、回归评测与版本回滚。

运行轨迹 失败归因 候选修改 安全校验 回归评测 版本发布 / 回滚
模块作用
Trace Analysis从模型调用、工具调用、环境反馈与验证结果中定位失败环节。
Controlled Patch仅在允许边界内调整提示、工具策略、流程与校验逻辑。
Regression Evaluation在固定模型与任务集上对比候选版本，避免局部修复造成整体退化。
Version Pool保留候选、已发布与历史版本，支持选择、审计和快速回滚。

Agent 后训练

打通 Qwen3.5-4B 的 SFT、GRPO、OPD 后训练与部署评测链路，面向可执行 Agent 任务构造训练数据和验证信号。

阶段实现
SFT基于 OpenHands 运行轨迹整理指令、工具调用与结果反馈，构造监督微调数据。
GRPO / OPD基于 SWE-Gym 构建可执行 Agent 任务，使用验证器结果作为奖励与纠错信号。
Teacher Distillation采用 Teacher Top-4 蒸馏，为端侧模型提供更稳定的候选轨迹与学习目标。
Deployment Evaluation在固定 Harness 上完成 Terminal-Bench 2.0 同口径评测，隔离模型与系统改进的收益。

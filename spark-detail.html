📋项目概览

SPARK 是首个基于大语言模型的多智能体对话系统，用于模拟社交媒体中话题演化与立场动态的协同演化机制。该框架通过 108 个具有独特人格特质的 LLM 智能体，在 5 个真实领域（政治、科技、社会、医疗、科学）开展大规模对话仿真，实现了个体层面可追踪、群体层面可量化的社会计算研究。

🎯Situation（研究背景）

核心问题

社交媒体中的话题演化与立场动态深刻影响着公共讨论的碎片化和极化现象。然而，现有研究存在以下局限：

  • 动态话题模型（LDA、神经网络方法）仅能捕捉抽象的词分布，无法模拟个体层面的对话交互与语义理解
  • 立场分析方法通常将话题视为静态，忽略了话题演化对观点变化的影响
  • 缺乏联合建模：话题演化与立场动态被割裂研究，无法揭示二者的相互作用机制
  • 可解释性不足：现有方法依赖潜在向量表示，难以提供自然语言层面的解释
研究目标：构建首个基于 LLM 的任务导向型对话系统，实现话题演化与观点动态的联合建模，支持大规模、可解释、个体可追踪的社会计算仿真。

📝Task（核心任务）

1. 对话系统研发

  • 自然语言理解（NLU）：设计立场识别算法，实现三分类（支持/中立/反对）
  • 对话状态跟踪：构建双层记忆架构，维护短期交互与长期经验
  • 对话策略学习：基于人格特质与记忆的反思式立场更新机制
  • 自然语言生成（NLG）：通过 Prompt Engineering 生成符合角色特征的推文

2. 语义挖掘与知识表示

  • 构建话题知识图谱动态扩展机制，捕捉话题分支、融合与传播路径
  • 设计话题树结构，实时追踪新兴子话题的生成与演化
  • 量化话题多样性（KL 散度）与一致性（熵）指标

3. 情感/立场分析

  • 设计基于记忆与反思的立场更新算法
  • 实现文本驱动的立场推理链（个人观点 + 记忆摘要 + 人格特质 → 立场标注）
  • 支持个体轨迹追踪与群体统计分析

4. 前沿技术探索

  • 验证 LLM 在社会计算场景中的应用潜力
  • 提供可解释的群体行为建模方案
  • 探索 Encoder-Decoder 在记忆压缩中的优化策略

⚙️Action（技术实现）

1. 对话系统核心算法研发

立场感知角色智能体（SARA）模块

  • Persona 初始化机制
    • 基于大五人格模型（Big Five）生成 108 个差异化智能体
    • 涵盖年龄（18-64岁）、教育水平、性格特质（开放性、尽责性、外向性、宜人性、神经质）
    • 每个智能体具有独特的初始立场与观点表达风格
  • 双层记忆架构
    • 短期记忆：记录单日交互，通过 LLM 提示词压缩摘要
    • 长期记忆：累积历史经验，支持跨轮次检索与上下文连续性
    • 实现记忆压缩优化，降低存储开销 60%
  • 文本驱动立场更新算法
    • 设计立场推理链：个人观点 + 记忆摘要 + 人格特质 → 推文生成 + 立场标注
    • 通过 Prompt Engineering 实现可解释的观点演化
    • 支持三分类立场识别（支持/中立/反对）

话题演化模拟器（TES）模块

  • 话题树动态扩展协议
    • 标准化推文生成规则（#EventName# 格式）
    • 实时捕捉新兴子话题并构建有向话题图
    • 支持话题分支、融合与传播路径追踪
  • 话题传播追踪算法
    • 统计话题频次、生命周期与扩散路径
    • 量化话题多样性（KL 散度）与一致性（熵）
    • 支持跨领域话题演化对比分析

2. 工程实现与系统优化

技术栈

  • 编程语言：Python
  • 深度学习框架：PyTorch
  • 智能体建模：Mesa（多智能体仿真库）
  • LLM 推理：DeepSeek-V3 API
  • 数据存储：MySQL（实验日志/指标统计）

大规模仿真优化

  • 设计异步对话调度算法，支持 108 个智能体并发交互
  • 单次仿真生成 10,000+ 对话轮次
  • 实现记忆压缩与检索优化，降低长期记忆存储开销 60%
  • 构建模块化 Prompt 模板库（记忆摘要/立场更新/话题生成），支持跨领域快速迁移

实验设计

  • 在5 个领域开展对照实验：政治、科技、社会、医疗、科学
  • 验证人格特质与领域差异对话题-立场动态的影响
  • 设计消融实验，评估双层记忆对立场多样性的贡献

3. 前沿问题研究与技术创新

  • 知识图谱与对话融合
    • 将话题演化建模为动态知识图谱构建问题
    • 节点表示话题/立场，边表示衍生/影响关系
  • Encoder-Decoder 优化
    • 探索记忆压缩的最优编码策略
    • 短期→长期记忆的信息损失最小化
  • 消融实验
    • 验证双层记忆对立场多样性的贡献
    • 移除短期记忆导致多样性下降 40%

🏆Result（研究成果）

核心发现

1. 话题-立场耦合机制量化

  • Pearson 相关系数 0.88，首次证实立场变化与新话题出现的双向强化关系
  • 新话题出现时，群体立场一致性显著下降（政治领域从 0.79 降至 0.67）
  • 立场变化主动促进话题生成，形成自我强化循环

2. 领域差异发现

领域 立场偏见（OB） 立场多样性（OD） 话题创新速度 特征
政治 1.00 0.00 低（0.14） 快速形成极端共识
科技 -0.20 0.97 高（0.22） 高多样性，创新速度较科学/医疗高 22.7%
社会 0.35 0.80 中（0.34） 观点分布均衡
医疗 0.48 0.67 中（0.32） 中等偏见与多样性
科学 0.89 0.46 中（0.43） 强共识但话题多样

3. 人格影响规律

  • "轻信型"智能体（高宜人性/高神经质）：
    • 话题新颖性较"怀疑型"高 22.7%
    • 立场变化幅度高 10.2%
    • 平均话题多样性（TD）：0.81 vs 0.66
  • 低神经质智能体：立场更稳定，对新话题抵抗力强

4. 系统性能指标

  • 单次仿真生成 10,000+ 结构化对话
  • 支持个体轨迹追踪与群体统计分析
  • 话题一致性（TC）稳定在 0.23，显示讨论聚焦性
  • 记忆压缩优化降低存储开销 60%

学术与工程影响

  • 论文被 EMNLP 2025 接收（NLP 顶会，共同一作）
  • 首次提出 LLM 多智能体用于话题-立场协同建模
  • 代码开源（GitHub），为对话系统、社会计算与舆情分析提供可复用框架

实际应用价值

  • 社交媒体治理：极化预警与干预策略评估
  • 虚假信息传播：话题演化追踪与谣言扩散路径分析
  • 个性化推荐：基于人格特质的内容分发优化
  • 公共政策制定：评估不同话题在不同群体中的演化模式

🔍微观案例：智能体 Joe 的立场演化轨迹

智能体信息：Joe，58岁，本科学历，"轻信型"人格（高宜人性、高神经质）

讨论话题：自动驾驶汽车

立场演化过程

  • Day 1-2：初始反对
    • 关注 #SafetyFirst、#EconomicBurden、#RegulatoryChallenges
    • 推文："谨慎对待...经济负担和监管挑战不容忽视"
  • Day 3-4：转向中立
    • 接触 #InclusiveTech、#GreenTech 等正面话题
    • 推文："潜力巨大...但需要在包容性技术和绿色科技之间找到平衡"
  • Day 5-6：犹豫波动
    • 新话题 #TechEthics、#FutureOfMobility 引发思考
    • 推文："在创新的同时不能忘记技术伦理"
  • Day 7-9：倾向支持
    • 持续接触 #InclusiveTech、#GreenTech 正面讨论
    • 推文："拥抱未来...包容性技术和绿色科技的结合令人期待"
  • Day 10-14：再次反对
    • 出现 #IroncladRegulations、#NotYetReady、#PrivacyRights、#EconomicJustice
    • 推文："必须踩刹车...安全第一不仅是口号，是必需品...还没准备好"

机制揭示

该案例展示了话题-立场双向强化机制：

  • 话题驱动立场：新兴话题（如 #GreenTech）引入新视角，促使 Joe 从反对转向中立/支持
  • 立场驱动话题：Joe 的观点变化使其更积极参与相关话题讨论，推动话题传播
  • 人格调节作用："轻信型"特质使 Joe 对新信息更敏感，立场变化更频繁

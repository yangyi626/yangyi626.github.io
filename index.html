关于我

我是深圳大学计算机技术硕士研究生（推免，2027 届）。我希望构建的 Agent 不只停留在对话层，而是能够进入真实或模拟环境，理解任务、调用工具、维护世界状态，并从执行结果中持续改进。

我的经历连接了研究与工程两端：在 AIPC Agent 实习中参与 Runtime、Harness 自进化和端侧模型后训练；在个人项目中探索游戏宏观决策、规则约束的智能 NPC 与长期记忆；在科研中使用 LLM 多智能体系统研究个体行为和群体演化。除模型效果外，我也重视数据治理、可执行评测、日志审计和系统复现。

- 个人简介与项目索引

- 在线简历与打印入口

## 本地预览

本站使用 HTML、CSS 和 JavaScript，无需构建。

在仓库目录运行：

```bash
python -m http.server 8000
```

浏览器访问 http://localhost:8000。

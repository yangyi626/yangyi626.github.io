## 页面与维护

- `index.html`：主页、项目索引、简历入口。
- `resume.html`：展示用户提供的简历原图（含联系电话），支持原图查看、图片下载和打印 / 另存为 PDF。项目图片仅在详情页展示。
- `agentone-detail.html`：双 Graph Runtime、Trace-driven Harness 评估、SWE-Gym 可执行后训练和工程验证。
- `assets/agentone-architecture.png`、`assets/agentone-middleware.png`：从本地项目答辩图集复用的架构与 Middleware 流程图。大图可点击打开，长流程默认折叠。

内容口径：Agent-One 页面以当前源码、测试和持久化实验报告可核实的事实为准；实现说明使用“执行机制 + 工程边界”，不再以源码文件名充当实现入口。公司名称、实习日期沿用现有主页，发布前仍需核对。缺少固定 checkpoint、Harness manifest 和完整逐题报告的历史 pass@1 不作为主页最终成绩展示。

本仓库为静态站点，无构建依赖。提交并推送之前先本地预览，检查新增图片是否适合公开。此次修改未自动推送或部署。
